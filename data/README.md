# Данные и локальные результаты

Источник: [UCI Default of Credit Card Clients](https://archive.ics.uci.edu/dataset/350/defaultofcreditcardclients). Автор — I-Cheng Yeh (2009), [DOI 10.24432/C55S3H](https://doi.org/10.24432/C55S3H), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). При повторном использовании сохраняйте атрибуцию.

## Получение

После установки зависимостей из корня проекта:

```bash
python -m src.run --download-only
python -m src.run
```

Первая команда получает данные, вторая выполняет полный анализ. См. [инструкцию запуска](../README.md).

Загрузчик использует [официальный ZIP UCI](https://archive.ics.uci.edu/static/public/350/default%2Bof%2Bcredit%2Bcard%2Bclients.zip) с файлом `default of credit card clients.xls` (около 5,3 MB). XLS читается pandas/xlrd с `header=1`: строка с индексом 1 содержит настоящие заголовки. Первый статус — `PAY_0`, затем `PAY_2`–`PAY_6`. Цель `default payment next month` переименована в `default`. URL и SHA-256 фактически использованного файла записаны в [метаданных](../exports/dataset_metadata.json).

`raw/` — локальный кэш официального источника, исключённый из Git. Повторный запуск использует кэш после проверки контрольной суммы. При отсутствии сети можно получить ZIP с официальной страницы другим способом, извлечь XLS и сохранить как `data/raw/default_of_credit_card_clients.xls`. Данные другого происхождения нельзя молча подставлять вместо официального файла: проверяется SHA-256.

## Схема и постановка

30 000 действующих клиентов Тайваня, 23 признака: лимит, пол, образование, семейное положение, возраст, шесть статусов платежей, шесть счетов и шесть предыдущих платежей. Суммы — NT$, возраст — годы. История — апрель–сентябрь 2005 года. ID в модель не входит. Цель 1 означает дефолт по платежу следующего месяца, 0 — его отсутствие по определению набора. Это не заявки на новый кредит и не фактические убытки. Случайное историческое разбиение не проверяет переносимость на будущие периоды.

## Разбиения и прогнозы

`generated/` создаётся запуском и исключён из Git:

- `splits.csv`: `row_position,split`, seed 42, стратифицированные train/validation/test 60% / 20% / 20%.
- `predictions_validation.csv`, `predictions_test.csv`: `row_position,y_true,probability,baseline_probability`, прогнозы логистической модели и константного baseline. Исходный ID не переносится.

Позиция строки — технический ключ воспроизведения, а не анонимизация: она позволяет сопоставить наблюдение с публичным исходным набором. Построчные данные не публикуются. Агрегаты — [exports/](../exports/), графики — [images/](../images/), методика — [отчёт](../report/report.md).
