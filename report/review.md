# Проверка готовности

Проверено 6 ноября 2026 года. Независимая роль проверки изучила исходный код, построчные локальные прогнозы и агрегированные результаты. Критических методологических замечаний не найдено. Финальную интеграцию и проверку воспроизводимости выполнил ведущий агент.

## Методология и числа

- Разбиение зафиксировано до EDA: 18 000 / 6 000 / 6 000, seed 42; все 30 000 позиций уникальны в membership, пересечений нет.
- ID и цель исключены из признаков. Импутация, масштабирование, one-hot, логистическая регрессия и prior baseline обучаются только на train.
- Порог 0,2 выбран на validation по заранее заданной политике: recall 0,608892, доля проверок 0,288833 ≤ 0,30. Политика записывается до расчёта test-прогнозов. Подбора по test и последующего переобучения нет.
- Независимый пересчёт test: TP=779, FP=949, TN=3724, FN=548; ROC-AUC=0,7594273634; AP=0,5254922910; Brier=0,1387997150. Precision=0,4508101852, recall=0,5870384326, FPR=0,2030815322, доля проверок=0,288.
- Суммы калибровочных интервалов равны 6 000 для каждой модели. Каждое разбиение по полу, возрасту и семейному положению восстанавливает общую матрицу ошибок.
- Качество данных: пропусков 0, повторов ID 0, полных дублей 0; повторов векторов признаков после первого — 56, дублей без ID с сохранением цели — 35. Строки сохранены. Совпадающие профили могут оказаться в разных выборках; это явно описано, тождество клиентов по ним не устанавливается.
- README, отчёт, EDA-заметки, таблицы и подписи графиков сверены. Различаются ассоциация и причинность, odds и вероятность, AP и трапециевидная PR-AUC, дополнительные проверки и отказы в выдаче кредита.

## Воспроизводимость и артефакты

Проверенная платформа — Windows, Python 3.12.14. Во второе новое venv установлены зависимости из `requirements-lock.txt`; `pip check` не обнаружил конфликтов. Полный анализ выполнен в отдельный выходной каталог с тем же официальным XLS, проверенным по SHA-256.

```text
python -m src.run
python -m src.run --output-root .verification/reproduction
python -m src.verify .verification/reproduction
python -m unittest discover -s tests -v
```

Команды запускались интерпретаторами соответствующих venv. Результат: **8/8 тестов пройдено**, **38 артефактов совпали**. CSV проверены с atol=1e-12 и rtol=1e-10; остальные документы и метаданные — по SHA-256; все 10 PNG — по целостности и равенству декодированных пикселей. [Машинный результат](../exports/reproduction_check.json).

Все 10 графиков также просмотрены визуально: оси, единицы, легенды и подписи читаемы. Наложение делений около нуля на графике денежных распределений исправлено. Главный риск калибровочного хвоста — всего 3 наблюдения в интервале [0,9; 1], а не доказательство идеальных вероятностей.

Построчные прогнозы, split membership, XLS, окружения и вспомогательные скрипты исключены из публикации через `.gitignore`. Источник, авторство и CC BY 4.0 указаны. Код workflow подготовлен для проверки на GitHub; локальная проверка не подменяет результат удалённого runner.
